## Task 14: Update wsgi.py

### Overview
Update the WSGI entry point to use the modular settings configuration.

### Dependencies
- Task 10: Create Django Project

### Instructions

1. **Open wsgi.py**
   - Located at `config/wsgi.py`

2. **Update DJANGO_SETTINGS_MODULE**
   - Ensure it points to `config.settings`
   - The settings module __init__.py handles environment

3. **Verify application callable**
   - Ensure `get_wsgi_application()` is called
   - Application is exposed as `application`

### wsgi.py Configuration

| Setting | Value |
|---------|-------|
| `DJANGO_SETTINGS_MODULE` | `config.settings` |
| Application callable | `application` |

### WSGI Purpose

| Aspect | Description |
|--------|-------------|
| **Protocol** | Web Server Gateway Interface |
| **Use Case** | Synchronous request handling |
| **Servers** | Gunicorn, uWSGI |
| **Production** | Primary entry point |

### Expected Outcome
- wsgi.py updated with correct settings path
- Ready for Gunicorn deployment

### Verification Checklist
- [ ] wsgi.py has correct DJANGO_SETTINGS_MODULE
- [ ] Application callable is exposed
- [ ] No import errors

## Task 17: Verify Django Installation

### Overview
Run Django system checks to verify the installation is correct and ready for development.

### Dependencies
- Task 16: Create urls.py Structure

### Instructions

1. **Navigate to backend directory**
   - Ensure in `backend/` directory
   - Virtual environment must be active

2. **Run Django check command**
   - Execute Django's system check framework
   - Look for any errors or warnings

3. **Review check output**
   - Ensure no critical errors
   - Address any warnings if present

4. **Test development server (briefly)**
   - Start development server
   - Verify it runs without errors
   - Stop server after verification

### Django Check Categories

| Category | What It Checks |
|----------|----------------|
| **System** | Settings, middleware |
| **Security** | Security settings |
| **URLs** | URL configuration |
| **Templates** | Template configuration |
| **Database** | Connection settings |

### Expected Check Output

A successful check shows:
- No critical errors
- May have warnings (acceptable for new project)
- System check message with count

### Common Initial Warnings

| Warning | Meaning | Action |
|---------|---------|--------|
| SECRET_KEY | Using default key | Will fix in settings |
| ALLOWED_HOSTS | Empty in production | Will set in production.py |
| Database | Not configured | Will configure later |

### Expected Outcome
- Django check passes
- No critical errors
- Development server can start

### Verification Checklist
- [ ] Django check command runs
- [ ] No critical errors reported
- [ ] Development server starts
- [ ] Can access admin URL in browser (optional)

## Task 18: Create Initial Migration Test

### Overview
Test the migration system by running showmigrations to verify Django can detect migrations.

### Dependencies
- Task 17: Verify Django Installation

### Instructions

1. **Run showmigrations command**
   - Execute Django's showmigrations command
   - Verify built-in apps have migrations

2. **Review migration list**
   - Check admin, auth, contenttypes, sessions
   - All should show as unapplied `[ ]`

3. **Verify migration system works**
   - Confirms Django can read migration files
   - Ready for database configuration

4. **Note: Do NOT run migrate yet**
   - Database not configured
   - Will run after PostgreSQL setup

### Built-in Django Migrations

| App | Migrations | Purpose |
|-----|------------|---------|
| `admin` | 3+ | Admin log entries |
| `auth` | 12+ | User, permissions |
| `contenttypes` | 2+ | Content types |
| `sessions` | 1 | Session storage |

### Expected Showmigrations Output

Shows list of built-in migrations:
- All marked with `[ ]` (unapplied)
- Migrations from admin, auth, contenttypes, sessions
- Ready for database

### Why Not Migrate Now?

| Reason | Explanation |
|--------|-------------|
| **No Database** | PostgreSQL not configured |
| **SQLite Default** | Would create unwanted SQLite |
| **Multi-Tenancy** | Needs django-tenants setup first |

### Expected Outcome
- showmigrations command works
- Built-in migrations are detected
- Migration system verified

### Verification Checklist
- [ ] showmigrations command runs
- [ ] Built-in app migrations listed
- [ ] No migration errors
- [ ] Did NOT run migrate command
